# Exporting API Documentation & Reproduction Sessions

API Dash allows developers to export active HTTP requests along with their live responses as clean, GitHub Flavored Markdown (`.md`) documentation or reproducible multi-line `cURL` sessions. This makes sharing API reproduction steps, filing bug reports in Jira or GitHub, and writing endpoint specifications fast and seamless.

---

## How to Export

1. **Send Request**: Configure and send any HTTP request (`GET`, `POST`, `PUT`, `DELETE`, `PATCH`, etc.) in the Request Editor until a response is received.
2. **Click Export Button**: In the **Response Pane Header** (located next to the status code and latency indicators), click the **"Export API Documentation"** icon button (`Icons.description_outlined`).
3. **Choose Export Format**:
   - **Markdown (.md)**: Formats the request headers, parameters, body, response metadata, and body into a structured technical document.
   - **cURL Session**: Generates an executable multi-line bash `curl` command with flags (`-X`, `-H`, `--data`, `-F`) and appends a commented response status summary (`# Response: 200 OK (45 ms)`).
4. **Copy or Save**:
   - Click **"Copy to Clipboard"** to copy the generated content for instant pasting.
   - Click **"Save to File"** to open your operating system's native file picker and save the file directly to your disk (suggested filename: `<request_name>_api_doc.md`).

---

## Layout Responsiveness

- **Desktop**: Renders as a 700x500 modal dialog with side-by-side or stacked syntax previews.
- **Mobile & Tablet**: Transitions to a full-width bottom sheet (`ExportDocumentSheet`) with scrolling code views and accessible button bars.

## Sample Markdown Output

Below is an example of the documentation generated by API Dash for a `POST` request with JSON body and response data:

````markdown
# Create New User

`POST` `https://api.apidash.dev/v1/users`

Creates a new user profile in the system.

### Headers

| Header | Value | Description |
| :--- | :--- | :--- |
| `Content-Type` | `application/json` | Request payload format |
| `Authorization` | `Bearer eyJhbGciOi...` | Bearer authentication token |

### Request Body

```json
{
  "name": "Jane Doe",
  "email": "jane.doe@example.com",
  "role": "engineer"
}
```

### Response

- **Status**: `201 Created`
- **Time**: `125 ms`

```json
{
  "id": "usr_987654",
  "name": "Jane Doe",
  "email": "jane.doe@example.com",
  "role": "engineer",
  "created_at": "2026-10-18T01:30:00Z"
}
```
````

## Sample cURL Session Output

Below is an example of the executable cURL session generated with reproduction comments:

```bash
curl -X POST \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer eyJhbGciOi..." \
  --data '{"name":"Jane Doe","email":"jane.doe@example.com","role":"engineer"}' \
  "https://api.apidash.dev/v1/users"

# Response: 201 Created (125 ms)
```

## Offline & Privacy Guarantee

All documentation and reproduction scripts are generated **100% locally on your machine**. Zero data is transmitted to external servers, cloud AI providers, or telemetry endpoints.
